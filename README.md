# Hebrew School Taskboard

זה ההוראות שקבלתי,
בני מערכת לניהול משימות לצוות בית ספר באמצעות Lovable.

המערכת צריכה לכלול:

הוספת משימה — כותרת, שם האחראי ותאריך יעד.

רשימת משימות — הצגת כל המשימות בצורה מסודרת.

שינוי סטטוס — פתוחה או הושלמה.

עיצוב מקצועי — בעברית, מימין לשמאל, נוח וברור לשימוש.

תעשה לי את זה בצורה הכי טובה ומקצועית ומהירה
